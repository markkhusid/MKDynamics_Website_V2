# Week 4 — Classification

The model lab predicts `Class` from the feature table built in week 2. The saved run standardizes the features, splits off a test set, and searches four models with 10-fold cross-validation. The score is accuracy.

| Algorithm | Test accuracy | Best cross-validation score |
| --- | ---: | ---: |
| Logistic regression | 0.833 | 0.846 |
| Support vector machine | 0.833 | 0.848 |
| Decision tree | 0.667 | 0.875 |
| K nearest neighbors | 0.833 | 0.848 |

Logistic regression, the support vector machine, and k-nearest neighbors each score 0.833 on the test rows. The decision tree has the highest cross-validation score, 0.875, and the lowest test accuracy, 0.667.
