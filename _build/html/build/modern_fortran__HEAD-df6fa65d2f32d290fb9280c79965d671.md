## Introduction

In this section we will be following along with the examples from \"[Modern Fortran: Building Efficient Parallel Applications](https://www.manning.com/books/modern-fortran)\" by Milan Curcic (Manning). We will use Jupyter Lab to facilitate rapid production of HTML content. The output of the Fortran code will be displayed in graphical format using Python scripts and Matplotlib.
