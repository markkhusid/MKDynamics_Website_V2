# Week 1 — Collect and clean

The first week builds the Falcon 9 table. A static copy of the SpaceX API response keeps the pull repeatable. The Wikipedia lab reads the snapshot of [List of Falcon 9 and Falcon Heavy launches](https://en.wikipedia.org/w/index.php?title=List_of_Falcon_9_and_Falcon_Heavy_launches&oldid=1027686922) from 8 June 2021. Wrangling then labels each flight.
