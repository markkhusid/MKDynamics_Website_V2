# AMD64

Created with Grok Build

This section is Fortran compiled for AMD64, the 64-bit x86 platform. The worked example is the same three-integer addition used on ARM64. The assembly here is Intel syntax, and the program body is a short frame that stores 1 and 9 and adds them in `eax`.
