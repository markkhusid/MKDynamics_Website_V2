This section is Fortran compiled for i386, the 32-bit x86 platform. The programs are the ones in the [Disassembling-Binaries i386 tree](https://github.com/markkhusid/Disassembling-Binaries/tree/master/Fortran/Intel_architecture/i386). The assembly is Intel syntax. A default `integer` and a default `real` are four bytes. Integer arithmetic stays in `eax`. Real addition uses the x87 unit. A read and a print call the gfortran runtime.

The listings come from the debug objects where the tree saved one. The multiply page uses the saved executable, because that directory has no separate object file. Addresses in an object start at 0. The notes on each listing were added to the objdump output.
