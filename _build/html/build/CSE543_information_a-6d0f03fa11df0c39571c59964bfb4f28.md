# CSE543 Information Assurance and Security

Created with Grok Build

Seven labs from a graduate information-assurance course: two classical ciphers, a set of crashing C programs, a web-application lab, TCP and UDP spoofing, and a small mutational fuzzer.

These pages are rewritten from the submissions. Assignment directions, names, student IDs, lab targets, crashing inputs, and working exploits stay off the site. Where a page shows code, the code is a new example of the idea. It is not the submission script, and it does not run the lab.
