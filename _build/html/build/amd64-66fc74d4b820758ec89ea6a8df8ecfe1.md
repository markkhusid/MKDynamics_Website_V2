# AMD64

Created with Grok Build

This section is Fortran compiled for AMD64, the 64-bit x86 platform. The examples are the same three-integer programs used on ARM64. The assembly is Intel syntax. Addition stores 1 and 9 and adds them in `eax`. Multiplication stores 2 and 3 and forms the product with `imul`.
