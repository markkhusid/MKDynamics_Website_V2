# Shapes, inheritance, and polymorphism

Created with Grok Build

`general_oop` is a single module, `shape_classes`, and a program that constructs the types in that module. The build is `gfortran` on `shape_classes.f90` and `main.f90`. CMake names the executable `oop1`.


## Types

`Particle` is a plain derived type with position, velocity, and mass. The program declares one and never uses it.

`Shape` keeps a private `pos(2)`. Its type-bound procedures are `init`, `set_pos`, and `print`, and `shape_destructor` is a final subroutine. An interface also named `Shape` makes `Shape()` call `shape_constructor`, which calls `shape_init`.

`Square` and `Circle` extend `Shape`. Each overrides `init` and `print`. `Square` adds `side`, set to 1 by `square_init`. `Circle` adds `radius`, set to 1 by `circle_init`, and a `set_radius` procedure. `circle_set_radius` declares the circle `intent(out)`, so a call would reset the rest of the object before storing the radius. The program does not call it.

`Point` stores `m_x` and `m_y`. `Triangle` stores three `PointElement` values, and each element holds a `class(Point)` pointer. `triangle_init` allocates three points at `(0, 0)`. `get_point` returns the pointer stored at the requested index.

`class(Shape)` is a polymorphic pointer. `type(Shape)` is not: it can hold only a `Shape`, not a `Square` or a `Circle`.

## What the program runs

`s = Shape()` runs the constructor. The final subroutine then runs for the temporary, which is why `shape_destructor` prints before the first `shape_print`. `set_pos(2, 2)` moves that shape.

`make_objects` is an internal subroutine. Its local shape is initialized, moved to `(5, 6)`, printed, and finalized when the subroutine returns.

An allocatable `Shape` is allocated, initialized, printed, and deallocated. A `Square` and a `Circle` are then initialized and printed. `square_print` prints the side and calls `shape_print`. `circle_print` prints the line `cirlce_print()`, which is the spelling in the source, then the radius and the parent print.

Two loops of 20 call `init` and `print` on a static `Shape` array and on an allocatable `Shape` array. A third loop of 20 allocates a `type(Shape)` pointer, stores it in `SimpleArrayElement`, prints through that pointer, and deallocates it. Those three loops repeat the same `shape_init` / `shape_print` lines. They are omitted from the excerpt below.

The polymorphic section allocates a `Square` and a `Circle`, initializes both, and points a `class(Shape)` pointer at each in turn. The print goes to `square_print` and then to `circle_print`.

The following loop allocates 20 squares into a `class(Shape)` array and prints them without calling `init`. `side` and `pos` are undefined on that path, so those lines are not a result. They are omitted here.

The triangle asks for point 1 three times:

```fortran
p_p0 => p_triangle % get_point(1)
p_p1 => p_triangle % get_point(1)
p_p2 => p_triangle % get_point(1)
```

All three pointers alias the first vertex. `set_pos(0, 0)`, then `(1, 0)`, then `(1, 1)` each write that same point, so the last write remains. Points 2 and 3 stay at the `(0, 0)` from `triangle_init`.
