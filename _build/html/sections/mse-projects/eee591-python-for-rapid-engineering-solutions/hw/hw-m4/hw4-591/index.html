Homework Module 4 — Classical Bit Demodulator (BPSK)

Built with Grok Build

Course: EEE591 / EEE419 Python for Rapid Engineering Solutions.

Executable walkthrough of HW4_591.py / HW4_591.ipynb. We simulate a classical BPSK communication link:

  1. Generate random bits and map them to phases 0 or π\piπ.

  2. Form the clean carrier samples xi(t)=cos⁡(ωt+ϕi)x_i(t)=\cos(\omega t + \phi_i)xi​(t)=cos(ωt+ϕi​).

  3. Add AWGN at the specified SNR to get yi(t)y_i(t)yi​(t).

  4. Recover each bit by least-squares projection onto {cos⁡ωt,sin⁡ωt}\{\cos\omega t,\sin\omega t\}{cosωt,sinωt}.

  5. Report Monte Carlo bit-error rate (BER).

Debug prints that were previously commented are enabled, and annotated plots show waveforms, the design basis, and the feature plane used for decisions.

Classical demodulator loop¶

For each bit:

  1. a=H⊤yia = H^\top y_ia=H⊤yi​

  2. c=b a=[A,B]⊤c = b\,a = [A,B]^\topc=ba=[A,B]⊤

  3. Decide b^i=1\hat b_i = 1b^i​=1 if A<0A<0A<0, else 0 (sign of the cosine coefficient).

# ================================================
# DECODING — CLASSICAL BIT DEMODULATOR
# ================================================
bits_array_hat = np.zeros(number_of_bits, dtype=int)
A_coeffs = np.zeros(number_of_bits)
B_coeffs = np.zeros(number_of_bits)

for i in range(number_of_bits):
    yi = y_of_t[i, :]
    a = np.dot(h.transpose(), yi)
    c = np.dot(b, a)
    A = c[0]
    B = c[1]
    A_coeffs[i] = A
    B_coeffs[i] = B
    bits_array_hat[i] = 1 if A < 0 else 0

print("bits_array (first 20)     =", bits_array[:20])
print("bits_array_hat (first 20) =", bits_array_hat[:20])

Takeaways¶

  • BPSK puts information in the sign of the in-phase coefficient AAA after LS fitting.

  • At SNR = 0 dB with only N=3N=3N=3 samples/bit, BER is non-negligible — noise can flip the sign of AAA.

  • Precomputing (H⊤H)−1(H^\top H)^{-1}(H⊤H)−1 keeps the Monte Carlo loop cheap for large NBN_BNB​.
