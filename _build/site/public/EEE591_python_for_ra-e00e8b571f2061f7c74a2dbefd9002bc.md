## Overview

This section collects coursework from **EEE591 / EEE419 Python for Rapid Engineering Solutions**
(ASU MSE Electrical Engineering). The course emphasizes using **Python as an engineering workbench**:
numerical methods, data analysis, circuit netlists and SPICE automation, signal processing,
machine learning on sensor data, and optimization of physical designs.

Work is organized into weekly **homework modules** and larger **projects** (including midterm and final).
Notebooks below are the primary graded-style deliverables; supporting scripts and datasets live
alongside each assignment in the repository.

## Course themes

| Theme | Where it appears |
|-------|------------------|
| Algorithms + DFT / FFT numerics | HW Modules 1–2 |
| Circuits, netlists, SPICE / ngspice automation | HW Module 3, Project 3–4 |
| Signals and data pipelines | HW Module 4, Project 1–2 |
| Classical ML / classification | Project 2 (sonar mine vs rock) |
| Modeling & missing-data analysis | Midterm & Final projects |
| Interactive tools & applications | HW Modules 10–13 |
