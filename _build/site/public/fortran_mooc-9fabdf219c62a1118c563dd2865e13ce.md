# Fortran MOOC

## Introduction
In this section we follow examples from **Fortran for scientific programming**, a MOOC hosted by FutureLearn. Course material is on GitHub:

[https://github.com/gjbex/Fortran-MOOC](https://github.com/gjbex/Fortran-MOOC)

We package each example with the **Fortran Package Manager (fpm)** and present it as an executable Jupyter notebook: source listing, step-by-step explanation, build, and run outputs.

Original course sources used here live under `Fortran_Code/OG_Source_Code/`. Working fpm projects are under `Fortran_Code/Section_*`.

## Topics covered so far
- Arrays, ball throw (ODE), bit manipulations, floating-point/IEEE, call-by semantics
- Cellular automata, computing π, implicit vs explicit loops, block matrices
- BLAS/LAPACK demos
- **New batch:** hello Fortran, GCD, leap year, calculator, recursion, enumerators, optional arguments
- Type info / overflow / conversions / precision timing
- Strings, summing stdin values, distances
- Random numbers/integers, Buffon's needle, Sierpinski chaos game, Box–Muller-style samples
- Primes, Fibonacci verification, Kaprekar, coin change, Towers of Hanoi
